# Screenshots

Both READMEs embed `docs/screenshots/sidebar.jpg` (1441×873) near the top, right below the badges.

To replace it:

1. Open VS Code with DSH installed and a URL configured.
2. Open the chat panel and make sure both the **URL** tab and the surrounding UI are visible.
3. Crop to roughly 1440×900 and save it here as `sidebar.jpg` (or `.png`, then update the `<img src="…">` in both READMEs).
4. No other edit is needed — the `<p align="center">…</p>` block is already live.

Keep screenshots free of anything personal: no tokens, no private URLs, no file paths that identify you.
