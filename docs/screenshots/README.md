# Screenshots

The READMEs reference `docs/screenshots/sidebar.png` from a commented-out block. To use it:

1. Open VS Code with DSH installed and a URL configured.
2. Open the chat panel and make sure both the **URL** tab and the surrounding UI are visible.
3. Crop to something around 1440×900 and save it here as `sidebar.png`.
4. Uncomment the `<p align="center">…</p>` block near the top of `README.md` and `README.zh-TW.md`.

Keep screenshots free of anything personal: no tokens, no private URLs, no file paths that identify you.
